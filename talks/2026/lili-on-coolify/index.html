Key Lessons

What Worked

  • File-based memory — simple, transparent, version-controlled
  • Cron-driven automation — isolated tasks in isolated sessions
  • DeepSeek V4 Flash — 1M context at $0.14/M tokens
  • SigNoz over Langfuse — native OTLP, no S3/MinIO needed
  • Two agents, one infra — marginal cost of second agent is almost zero

What I'd Do Differently

  • OTel plugin took too long — had to patch OpenClaw source for OTel SDK v2 API changes
  • PDF via pandoc stripped CSS — switched to Chrome CDP, lesson: test rendering early
  • Email attachment MIME bug — silently dropped attachments, had to rewrite
  • Oracle Cloud free tier — wasted an hour on ARM capacity issues. Hetzner just works.
  • Langfuse S3 dependency — required MinIO for blob storage. SigNoz doesn't.

What's Next

  • Nini research pipeline — 23 tasks assigned, weekly brief cron enabled
  • Multi-agent content pipeline — blog → newsletter → social automation
  • Ekathi multiplayer gaming — PartyKit-powered real-time game rooms
  • Career transition — EM-track, BBSR relocation, expert networks
  • Third agent? — If coordination pattern works, another agent joins
